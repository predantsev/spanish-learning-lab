## ID conventions other ranges should cite

- Regular present families: the bare ID is the **singular person group** (yo, tú, él/ella/usted)
  and carries the stem + ending rule; the `.plural` suffix holds nosotros, vosotros (Spain),
  ellos/ellas/ustedes: `present.regular-ar` / `present.regular-ar.plural`, same for `-er`, `-ir`;
  `contrast.er-ir-endings` holds the nosotros/vosotros difference.
- Irregular present verbs: one skill per verb, all six persons: `present.ser`, `present.estar`,
  `present.tener` (taught before the regular families, so `kind: form` without `exceptionOf`);
  `present.ir`, `present.hacer`, `present.preferir`, `present.querer` (`kind: exception`,
  `exceptionOf` the regular family). `present.preferir`/`present.querer` are the first e→ie verbs;
  `cuesta/cuestan` (costar) and `cierra/cierran` (cerrar) are taught only as fixed 3rd-person forms
  inside `price.ask-answer` and `time.abre-cierra` — A2-01 owns the stem-change groups.
- Same singular/`.plural` split: `pron.subject` / `pron.subject.plural`,
  `gustar.pronouns` / `gustar.pronouns.plural`.

## Lexicon ID rule

`lex.` + lemma lowercased, diacritics folded (á→a, é→e, í→i, ó→o, ú→u, ñ→n, ü→u), spaces →
`-`, punctuation (¿ ? ¡ ! . , : ; ’ " ( )) removed. Homographs get a dot suffix naming the use:
`.adv`, `.noun`, `.num`, `.interj` — `lex.manana.adv` (tomorrow, A1-01) / `lex.manana.noun`
(morning, A1-04); `lex.tarde.adv` / `lex.tarde.noun`; `lex.primero` (ordinal, A1-05) /
`lex.primero.adv` (A1-04); `lex.cuarto.num` / `lex.cuarto.noun`; `lex.claro.interj`. Nouns with
independent gender pairs get one item each (`chico`/`chica`, `amigo`/`amiga`, `profesor`/`profesora`,
`señor`/`señora`); otherwise one masculine item with the feminine form in `noteUk`. Adjectives use
the masculine singular lemma with the other forms in `noteUk`. Multiword items use `pos: expression`
(or `preposition` for `encima de`, `al lado de` …). Function words already owned by a skill
(articles, possessives, subject pronouns, question words) are not duplicated as lexicon items.

  (`a mí` appears only inside fixed gustar responses).
