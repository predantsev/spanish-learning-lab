# A1-A2 curriculum working draft

Updated: 2026-10-08. Status: outline and brief familiar-foundations approach accepted by the owner on 2026-10-08; detailed lessons remain a working draft, not an approved final syllabus, authored course, or implementation. Confirmed scope and product decisions remain in [COURSE-DESIGN.md](COURSE-DESIGN.md), especially C-024 through C-029. This document owns the detailed A1-A2 curriculum work.

## Purpose and boundaries

Build from beginner foundations to a strong A2-aligned reading/writing curriculum, with grammar and vocabulary supporting practical written tasks. Repeated practice and personal phrases operate throughout. Speaking/conversation is excluded; listening-only activities remain undecided. No overall CEFR proficiency claim is implied.

Spanish of Spain is the main variety (C-028). The initial interface, instructions, explanations, hints, and feedback are Ukrainian only, with future localization planned under C-030/C-031. Spanish remains the language being studied.

The map below is an original teaching sequence accepted as the planning outline under C-029, informed by sources S1-S3. It is not the sequence prescribed by Instituto Cervantes, and the grouping is not a fixed lesson count. Each row will need smaller lessons, reviewed examples, explicit accepted answers, and delayed checks. Topic familiarity may change pacing; it must not fabricate mastery evidence.

Prerequisites express dependencies, not mandatory completion of every earlier exercise. In particular A2-06 needs prior exposure to each tense being contrasted. Detailed sequencing can be refined during complete objective mapping; Spanish of Spain is now selected.

## Threads that must not disappear between blocks

- Situations: identity, relationships, home, daily routine, food, shopping, transport, time, study/work, leisure, appointments, and simple problems. These are proposed context families, not a fixed word list.
- Reading and writing: introduce short notices, forms, descriptions, schedules, and messages throughout; do not postpone all meaningful text work until the final block.
- Language detail: expand questions/negation, pronouns, prepositions, quantifiers, comparatives, connectors, and orthography alongside the headline verb topics. A tense-only syllabus would not meet the proposed curriculum.
- Learning evidence: distinguish recognizing, recalling a form, using it in a sentence, and selecting it in context. Track targeted hints and answer reveals locally to the assessed skill.
- Personal phrases: allow saving from a lesson, adding an external phrase, and capturing Ukrainian intent; only checked entries become practice models. Reuse both phrases and appropriate variations.
- Review: revisit old skills in new but familiar contexts, including later sessions; the exact interval algorithm remains open. Do not introduce unknown grammar into a supposed recall check without explaining it.

## First block to detail together: A1-01

Proposed outcome: the learner can read and type the written forms needed by later lessons and understand basic exercise instructions. This is a brief foundation whose pacing can adapt for a returning learner.

Candidate micro-lessons (grouping remains open):

1. Spanish characters and practical entry of accented vowels, ñ, ü, ¿, and ¡, including a phone keyboard.
2. Word stress and written accent marks, introduced through a small set of checked words rather than a large rule dump.
3. Sentence boundaries, question/exclamation punctuation, and capitalization.
4. Minimal learning vocabulary: noun, verb, person, singular/plural, infinitive; explain each only when needed in a real task.
5. A short independent reading/typing check, followed by a later return using different words.

Exercise candidates: identify a written form, enter a short item from a meaning cue, repair punctuation, and transfer the same skill into a small sentence. Do not assess a new verb ending when the declared target is keyboard entry. Letter-sound material, if included for reading support, does not authorize spoken practice; any audio remains a separate scope decision.

Accepted handling of familiar foundations (C-029): offer a short optional self-check and direct access to practice without forcing a long introduction. Detailed thresholds and evidence rules remain to be designed; skipping an introduction does not certify mastery.

## Example of later detailed design: A2-03

This example is a design sketch chosen because tense forms and exceptions motivated the product; it is not the next module to implement.

Separate skill records for auxiliary selection, regular participle formation, individual irregular forms, word order, and tense choice. A prompt naming the tense checks formation; a later prompt with sufficient context and no tense label checks selection. A missing vocabulary item must not automatically become a tense error.

Possible loop: concise rule reference -> targeted form practice -> contextual gap -> short written production -> later mixed review. Use progressive hints that identify the assistance category. Independent follow-up must use a new prompt, not merely repeat a just-revealed answer. Review and validate permissible alternative wording before release.

## Method for detailing each block

For every block, record: objective IDs; small prerequisite skills; proposed micro-lessons; practical text contexts; independent tasks; hint levels; acceptable-answer policy; likely confusions; return points; personal-phrase opportunities; phone interaction; and source/linguistic-review status. Content IDs must remain stable as the outline evolves.

Next steps: discuss the learning-session flow, then detail the blocks incrementally within the accepted outline. The first draft does not establish complete A1/A2 coverage. Before course release, reconcile the relevant inventories and objectives with explicit coverage or justified scope exclusions.
