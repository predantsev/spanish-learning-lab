# Spanish Learning Lab — як користуватися

Це локальний застосунок для вивчення іспанської (Іспанія) з українським інтерфейсом. Він працює лише на цьому Mac, без облікового запису, хмари та інтернету. Ваші відповіді й прогрес зберігаються тільки тут:

`~/Library/Application Support/Spanish Learning Lab/`

У цій папці (з програмою) немає жодних ваших даних. Її можна оновлювати чи видаляти — профіль від цього не зміниться.

## Запуск

Двічі клацніть **Start.command**. Відкриється вікно «Термінал», застосунок запуститься й відкриється в браузері за адресою на кшталт `http://spanish-learning-lab.localhost:<порт>`.

- Застосунок продовжує працювати, навіть якщо закрити вкладку браузера або вікно «Термінал».
- Повторний запуск не створює другу копію: відкривається вже запущений застосунок.
- Якщо адреса `spanish-learning-lab.localhost` не відкривається, використайте запасну адресу (див. «Відкрити ще раз»).

## Команди (у «Терміналі», з цієї папки)

Усі команди використовують Node, що лежить у цій папці; нічого не встановлюється в систему.

| Що потрібно | Команда |
|---|---|
| Запустити й відкрити | `runtime/node/bin/node app/bin/sll.mjs start --open` |
| Перевірити стан | `runtime/node/bin/node app/bin/sll.mjs status` |
| Відкрити ще раз | `runtime/node/bin/node app/bin/sll.mjs open` |
| Відкрити через запасну адресу 127.0.0.1 | `runtime/node/bin/node app/bin/sll.mjs open --loopback` |
| Зупинити | `runtime/node/bin/node app/bin/sll.mjs stop` |
| Резервна копія зараз | `runtime/node/bin/node app/bin/sll.mjs backup` |
| Експорт профілю в файл | `runtime/node/bin/node app/bin/sll.mjs export --out ~/Desktop/мій-профіль.zip` |
| Повний експорт разом із навчальними матеріалами | додайте `--self-contained` |
| Переглянути відновлення з архіву | `runtime/node/bin/node app/bin/sll.mjs restore --preview <архів.zip>` |
| Підтвердити відновлення | команду з точним кодом показує попередній перегляд |

Кожне посилання для відкриття діє 60 секунд і лише один раз; щоб відкрити застосунок пізніше, просто виконайте `open` знову.

## Резервні копії

- Застосунок сам робить перевірені резервні копії: після змін (не частіше ніж раз на 15 хвилин), під час запуску, якщо остання копія застаріла, і під час звичайної зупинки.
- Зберігаються 7 останніх днів зі змінами, 4 тижневі копії, 5 копій перед важливими змінами (оновлення, відновлення) і остання копія для відкату.
- Ці копії лежать на тому самому диску, тож **не захищають від втрати чи поломки диска**. Час від часу робіть експорт (`export`) і зберігайте файл на іншому носії.
- Експорт містить ваші відповіді, тому зберігайте його приватно. У ньому немає паролів, ключів доступу агентів чи сесій браузера.

## Відновлення з архіву

Відновлення **повністю замінює** поточний профіль профілем з архіву (об'єднання двох профілів не підтримується).

1. `restore --preview <архів.zip>` перевіряє архів (розмір, структуру, цілісність) і показує, що буде відновлено: профіль, кількість спроб і чернеток, відсутні аудіофайли.
2. Попередній перегляд дає одноразовий код, дійсний 5 хвилин. Підтвердження працює, лише якщо профіль за цей час не змінився.
3. Перед заміною застосунок робить і перевіряє резервну копію поточного профілю; якщо вона не вдається, нічого не замінюється.
4. Якщо під час заміни станеться збій, під час наступного запуску буде автоматично повернуто попередній профіль.
5. Після відновлення попередні входи в браузері недійсні — відкрийте застосунок знову командою `open`.

Якщо архів створено на іншому комп'ютері, підтвердження може вимагати параметр `--trust-imported-provenance`: це означає, що записи перевірок з архіву не можна перевірити ключем цього Mac. Додавайте його, лише якщо довіряєте джерелу архіву.

## Якщо macOS просить дозволу

macOS може попередити, що не може перевірити розробника `Start.command` або `runtime/node/bin/node`. Застосунок ніколи не обходить цю перевірку й не змінює налаштувань безпеки. Якщо ви впевнені, що файл саме з цієї папки, ви можете самостійно дозволити його через **Системні параметри → Конфіденційність і безпека → «Усе одно відкрити»** для названого файлу. Якщо сумніваєтеся — не дозволяйте й зверніться до того, хто передав вам цю папку.

## Журнали

Технічні журнали: `~/Library/Application Support/Spanish Learning Lab/logs/` (до 3 файлів по 5 МБ). Вони не містять ваших відповідей, чернеток чи ключів.
