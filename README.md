# Spanish Learning Lab

A Spanish-learning course being designed around sustained practice and revisiting previously studied material.

**Phase: developer handoff plan prepared; implementation requires a separate owner instruction. No application has been implemented.**

The owner requested a public repository on 2026-10-07 and a discussion-first process inspired by JavaScript Learning Lab: discuss ideas, answer questions, document the intended course, and only then authorize implementation.

Spanish of Spain is the main course variety. The initial interface and instructional content will be Ukrainian only, with future localization planned. The course is planned from beginner foundations through at least B2, delivered as beginner-to-A2 first, then B1 and B2. Listening practice targeting Spain Spanish is planned, initially using reviewed synthetic audio with suitable existing human recordings as later additions, starting with everyday phrases and expanding to sentences and texts, with adaptive review of auditory recognition. Speaking/conversation is excluded; level labels guide the in-scope curriculum rather than certify overall proficiency. Initial delivery is local browser use on the owner's computer; mobile-friendly layouts and a dedicated visual-design exploration stage remain planned. Hosting, remote phone access, and cross-device sync are deferred. Private local progress, automatic backups, export/import, and history-preserving updates are planned. The first owner handoff requires the complete agreed application and reviewed beginner-to-A2 materials, locally available for ordinary offline practice; internal pilots do not replace that handoff. The first release also includes a bounded external-assistant API and repository-contained skill, with context access, observed help recording, reviewed practice-set creation, private drafts, and verified supported changes. MCP is optional later; no API or skill has been implemented. The handoff selects technical and recovery defaults, with alternatives and revisit triggers recorded. Concrete lesson/task/audio authoring and its review gates are execution work; public distribution licensing remains deferred. Public visibility does not select a license. Do not import private learning records or third-party lesson materials into this repository.
