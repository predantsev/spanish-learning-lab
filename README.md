# Spanish Learning Lab

A Spanish-learning course being designed around sustained practice and revisiting previously studied material.

**Phase: discovery and course design. No application has been implemented.**

The owner requested a public repository on 2026-10-07 and a discussion-first process inspired by JavaScript Learning Lab: discuss ideas, answer questions, document the intended course, and only then authorize implementation.

- [Course design](docs/COURSE-DESIGN.md): confirmed intent, proposals, and open questions.
- [A1-A2 curriculum draft](docs/CURRICULUM-A1-A2.md): accepted first-stage outline and draft detailed planning.
- [Current status](docs/STATUS.md): the next discussion and delivery state.
- [Contributor instructions](AGENTS.md): scope and workflow.

Spanish of Spain is the main course variety. The initial interface and instructional content will be Ukrainian only, with future localization planned. The course is planned from beginner foundations through at least B2, delivered as beginner-to-A2 first, then B1 and B2. Listening practice targeting Spain Spanish is planned, initially using reviewed synthetic audio with suitable existing human recordings as later additions, starting with everyday phrases and expanding to sentences and texts, with adaptive review of auditory recognition. Speaking/conversation is excluded; level labels guide the in-scope curriculum rather than certify overall proficiency. Initial delivery is local browser use on the owner's computer; mobile-friendly layouts and a dedicated visual-design exploration stage remain planned. Hosting, remote phone access, and cross-device sync are deferred. Detailed curriculum, implementation technology, progress backup/recovery, and license remain undecided. Public visibility does not select a license. Do not import private learning records or third-party lesson materials into this repository.
